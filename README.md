# GitHub Desktop Demo Repo

A tiny practice repo for learning the basic GitHub workflow with **GitHub Desktop**.
No coding experience needed.

## The workflow we'll practice

1. **Clone** – get a copy of this repo on your computer
   *GitHub Desktop → File → Clone Repository*
2. **Branch** – make a safe place to work
   *Current Branch → New Branch → name it `add-your-name`*
3. **Edit** – open `students.md` and add your name to the list
4. **Commit** – save a snapshot of your change
   *Write a short summary in the bottom-left box → Commit to your branch*
5. **Push** – send your branch to GitHub
   *Click "Publish branch" / "Push origin"*
6. **Pull Request** – ask to merge your branch into `main`
   *Click "Create Pull Request" → fill in the form on GitHub → Create*

## Files

- `students.md` – the file everyone edits (add your name here)
- `fun-facts.md` – optional second file if you want to practice more edits

## Tips

- Commit messages should say *what* you changed: `Add Tyler to student list`
- One branch = one idea. Keep changes small.
- Never be afraid to make a mistake — that's what branches are for.
